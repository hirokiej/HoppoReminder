# ほっぽリマインダー

## このサービスでできること

- ピアノ教室などの先生が生徒のレッスンスケジュールに変更があった場合に公式ラインでトークを自動リマインドすることができます。
- スケジュール変更した時点でリマインダーが設定されるので、「スケジュール変更忘れ」を防ぐことができます。
- 「送信したい友達」、「元のスケジュールの日時」、「変更後のスケジュールの日時」を選択して予約ボタンを押すだけです。
- Google アカウントとも連携するので、カレンダーにスケジュールを同時に登録することもできます。
- 生徒に送信されるトークは 3 通あります。
  - スケジュールが変更された旨のお知らせが、変更時に届きます。
  - 元々のスケジュールの前日に「明日はレッスンがない」ことをお知らせします。
  - 変更したスケジュールの前日に「明日はレッスンがあります」と言った内容をお知らせします。
